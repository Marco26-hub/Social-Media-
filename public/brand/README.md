Il master ufficiale e `swa-logo-official.png`.

- non ridisegnare o modificare la geometria;
- non alterare proporzioni, colori o posizione degli accenti;
- usare il file trasparente su fondi scuri;
- su fondi chiari applicare un supporto verde SWA `#153B32`;
- derivare ogni formato social, stampa o web esclusivamente dal master ufficiale.
